# 🦟 App-Game-Mata_Mosquito

Projeto desenvolvido com foco em prática de lógica de programação, manipulação do DOM, interatividade e desenvolvimento de aplicações web/mobile simples.

O objetivo do jogo é eliminar os mosquitos que aparecem na tela antes que o tempo acabe. Conforme o jogo avança, o desafio aumenta, exigindo mais atenção e velocidade do jogador.

---

## 🚀 Funcionalidades

* Sistema de pontuação
* Controle de vidas
* Temporizador da partida
* Mosquitos aparecendo em posições aleatórias
* Diferentes níveis de dificuldade
* Interface responsiva
* Reinício de jogo

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

---

## 🎯 Objetivo do projeto

Este projeto foi criado para desenvolver habilidades práticas em:

* Lógica de programação

* Temporização com `setInterval` e `setTimeout`

* Organização de código

---

## 📱 Demonstração

O jogador deve clicar nos mosquitos antes que desapareçam da tela. Caso contrário, perde vidas. O jogo termina quando o tempo acaba ou todas as vidas são perdidas.
